
# SRG Mobile 1.4.50

Poprawiono cykliczne wyświetlanie przesiadek POLREGIO na Sędziszów Małopolski Grunwaldzka (stacja PKP Sędziszów Małopolski Wschodni). Po powrocie z widoku trasy ekran przesiadek jest odtwarzany ponownie. Testy uwzględniają przejścia czasowe cyklu LCD oraz blokują mylne przypisanie danych do innego numeru przystanku.

Uruchomiono wszystkie testy Node.js z katalogu tests/ (18/18 OK).
